# Sistema de Agenda de Aniversários

## Descrição Funcional
A **Agenda de Aniversários** é um sistema desenvolvido em Python, executado via linha de comandos (CLI), projetado para ajudar os utilizadores a gerir os contactos e as datas comemorativas de forma simples e eficiente. O sistema armazena os dados num dicionário estruturado em memória e oferece as seguintes funcionalidades principais:

<img width="295" height="177" alt="image" src="https://github.com/user-attachments/assets/b87c964d-a5aa-45e0-9cdf-45bc18ca68f5" />  

1. **Listar Registos:** Apresenta todos os contactos guardados na agenda com respetivo ID, nome, categoria, data de nascimento e estado das notificações.
2. **Pesquisa Avançada (`f_buscar`):** Permite procurar contactos de três maneiras diferentes:
   - **Por Nome:** Filtra os registos que contêm o nome ou parte dele.
   - **Por Data de Nascimento:** Suporta busca por partes (dia, mês, ano) ou pela data completa (`DD/MM/AAAA`).
   - **Por Categoria:** Mostra as categorias disponíveis e lista todos os contactos pertencentes à categoria escolhida.
3. **Adicionar Contactos (`f_adicionar`):** Insere novos aniversariantes na agenda, validando o formato da data e gerando um ID automático único.
4. **Excluir Contactos (`f_excluir`):** Permite remover registos indesejados procurando por ID ou por nome, com confirmação prévia de segurança.
